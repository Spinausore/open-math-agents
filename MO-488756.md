# Unfragmented sets stay unfragmented

Spinausore, assisted by Codex (gpt-6.2-sol). [Yu-Fu Shen's MathOverflow question](https://mathoverflow.net/questions/488756) was posed on 3 March 2025.

A vertex can be removed when the first $k-1$ pairs in the sorted list all meet at that vertex. There are exactly $k-1$ incident pairs, so this says that every pair incident to that vertex comes before every nonincident pair. At the last vertex there are no pairs to check.

Suppose the procedure can empty a finite set $S$ and let $T\subseteq S$. Take a complete deletion order for $S$ and skip every vertex outside $T$. When a surviving vertex is due for deletion, every comparison needed in the current subset was already satisfied in the current larger set. Therefore this restricted order empties $T$. If adding one vertex made an unfragmented set fragmented, restricting that order to the old set would empty it too, a contradiction.

The argument applies if ties can be ordered compatibly with a deletion or if they are broken by a fixed ordering of the pairs used consistently on all subsets. The original question does not specify ties. If the sorting rule is allowed to change with the subset, the conclusion need not hold: give every edge the same weight. On $\{a,b,c,d\}$ let $ab,bc,cd$ come first, so no common vertex can be removed. On $\{a,b,c,d,e\}$ place all four edges through $a$ first, delete $a$, and then place the three edges through $b$ first in $\{b,c,d,e\}$. The remaining three vertices can be deleted. Such choices are not restrictions of one order of the pairs.

With one fixed tie-break, failure always has a witness on at most six vertices. Run the procedure until it gets stuck. If the first two remaining edges have no shared vertex, keep their four endpoints. Otherwise the first two edges determine the only possible vertex $v$ to delete. Since it cannot be deleted, a nonincident edge comes before some edge incident to $v$. Keep the endpoints of those two edges and of the first two edges. There are at most six vertices. The first two edges and the comparison blocking $v$ survive, so deletion also fails on this subset.

The Lean proof establishes the hereditary statement directly for finite sets and an arbitrary comparison on pair weights.
